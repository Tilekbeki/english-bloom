# English Bloom

Учебный проект для изучения английских слов и фраз через **интервальное повторение**. Идея приложения — возвращаться к изученному материалу через промежутки времени и вспоминать ответ до просмотра перевода.

Проект развивается по заданиям курса Angular. Доступны главная страница, словарь из архива Memrise, грамматические правила и разговорные фразы. В ДЗ №7 страницы подключены через Angular Router, а состояние фильтров словаря хранится в URL.

## Идея интервального повторения

1. Познакомиться со словом или фразой: прочитать перевод и пример употребления.
2. Попытаться вспомнить значение без подсказки, проверить себя и оценить ответ.
3. Вернуться к карточке через время. После уверенного ответа интервал может увеличиваться, после ошибки — сокращаться.

Последовательность «через 1 день → 3 дня → 7 дней» на странице иллюстрирует принцип. Это не универсальное расписание и не результат работающего алгоритма.

В следующих этапах планируются личные наборы карточек, очередь повторений на сегодня, оценка сложности ответа и история прогресса.

## Запуск

Используйте **Node.js 24.19.0** (версия записана в `.nvmrc`) и npm. При установленном nvm:

```bash
nvm install
nvm use
npm ci
npm start
```

Без nvm установите Node.js 24.19.0 и выполните `npm ci`, затем `npm start` в каталоге проекта.

Откройте <http://localhost:4200/>. Если порт занят:

```bash
npm start -- --port 4300
```

## Сборка и проверка

```bash
npm run build
npm test -- --watch=false
```

Production-сборка создаётся в `dist/english-bloom/browser/`. Команда сборки не запускает сервер.

## Компоненты

| Компонент        | Назначение                                                  |
| ---------------- | ----------------------------------------------------------- |
| `Header`         | Логотип и ссылки на разделы страницы                        |
| `Hero`           | Приветствие, идея проекта и иллюстрация                     |
| `LearningTracks` | Три шага: знакомство, вспоминание и интервальное повторение |
| `WordOfDay`      | Статический пример карточки bloom с переводом и фразой      |
| `Footer`         | Информация о проекте и ссылка наверх                        |

Главную страницу собирает `Main` в `src/app/pages/main/`. В него входят `Hero`, `LearningTracks` и `WordOfDay`. Корневой `App` подключает `Header`, `RouterOutlet` и `Footer`. Router выводит выбранную страницу в общей оболочке. У каждого компонента отдельные `.ts`, `.html` и `.scss` файлы; общие стили находятся в `src/styles.scss`.

## Маршруты ДЗ №7

| Адрес | Страница |
| --- | --- |
| / | Главная |
| /home | Перенаправление на / |
| /vocabulary | Список слов |
| /vocabulary/:id | Карточка слова с идентификатором из Memrise |
| /rules | Правила |
| /phrases | Фразы после учебного входа |
| /login | Учебный вход |
| Любой неизвестный адрес | Страница «Страница не найдена» |

Маршруты описаны в src/app/app.routes.ts и подключены через provideRouter в app.config.ts. У словаря общий VocabularyLayout с собственным router-outlet. Список и карточка слова являются дочерними маршрутами. Главная загружается сразу, остальные страницы используют loadComponent.

Словарь поддерживает query-параметры q (поиск), deck (название колоды) и page (количество показанных порций по 24 карточки). Например, /vocabulary?q=tour&page=2. Фильтры и число карточек восстанавливаются после обновления страницы. Переход в карточку и ссылка «Все слова» сохраняют эти параметры. withComponentInputBinding передаёт id и query-параметры в inputs страниц, включая переход между разными id без пересоздания компонента.

Функциональный phrasesGuard проверяет signedIn в root-сервисе DemoSession. Гость при открытии /phrases попадает на /login?returnUrl=%2Fphrases. Кнопка «Войти» включает учебный флаг и возвращает к фразам, «Выйти» сбрасывает его и открывает главную. Флаг хранится в памяти и сбрасывается при перезагрузке. Это демонстрация guard для задания, авторизация на сервере отсутствует.

Проверить поведение можно следующими шагами.

1. Откройте /, /rules и /vocabulary напрямую, проверьте активную ссылку и кнопки браузера «Назад»/«Вперёд».
2. В словаре задайте поиск, выберите колоду и нажмите «Показать ещё». Обновите страницу и проверьте восстановление фильтров.
3. Откройте слово, скопируйте его URL и откройте напрямую. Нажмите «Следующее слово» и «Все слова».
4. Откройте /home и неизвестный адрес, проверьте перенаправление и страницу 404.
5. Откройте /phrases гостем, выполните учебный вход, затем выйдите и повторите переход.
6. В DevTools → Network проверьте, что код страницы подгружается при первом переходе. Выполните npm run build.

При публикации статической сборки сервер должен возвращать index.html для URL приложения, сохраняя обычную раздачу файлов data и JavaScript. Это позволяет напрямую открывать вложенные маршруты. ng serve уже поддерживает такое поведение.

## Настройки проекта

- Angular 22 и TypeScript; проект создан через Angular CLI.
- Стили SCSS, адаптивная вёрстка для компьютеров и телефонов.
- SSR/SSG и конфигурации AI-инструментов отключены.
- «Словарь» через `MemriseApi` загружает локальный архив Anki из `data/Memrise.apkg`. Angular копирует архив и модуль SQLite в папку `data` при сборке. Сервис читает колоды и поля `Front / Back` в браузере.
- Навигация использует Angular Router, routerLink и routerLinkActive. Главная, словарь, правила и фразы имеют собственные URL.
- Шрифты системные; иллюстрация и favicon — локальные SVG. Внешние сервисы и ключи не нужны.
- `node_modules/`, `dist/` и `.angular/` исключены из Git. `package-lock.json` сохранён для воспроизводимой установки.

Команда создания основы:

```bash
npx @angular/cli@22 new english-bloom --style=scss --routing=false --ssr=false --ai-config=none --package-manager=npm
```

Компоненты создавались командой `ng generate component <name> --skip-tests`. Настройка двух существующих тестов корневого компонента адаптирована к Angular Router.

Документация: [установка Angular](https://angular.dev/installation), [Angular CLI](https://angular.dev/cli), [компоненты](https://angular.dev/guide/components).
