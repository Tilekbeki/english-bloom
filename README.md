# English Bloom

Учебный проект для изучения английского языка. Идея приложения — помогать начинающим пополнять словарный запас, разбираться в грамматике и узнавать фразы для повседневного общения.

Проект выполнен по домашнему заданию №2 курса Angular. На этом этапе реализована статическая главная страница: знакомство с проектом, три направления изучения языка и пример слова дня. Слово дня задано в HTML и не обновляется автоматически. Упражнения, пользовательский прогресс и словарь — идеи для следующих этапов, а не готовые функции.

## Запуск

Используйте **Node.js 24.19.0** (версия записана в `.nvmrc`) и npm. При установленном nvm:

```bash
nvm install
nvm use
npm ci
npm start
```

Без nvm установите Node.js 24.19.0 и выполните `npm ci`, затем `npm start` в каталоге проекта.

Откройте <http://localhost:4200/>. Если порт занят:

```bash
npm start -- --port 4300
```

## Сборка и проверка

```bash
npm run build
npm test -- --watch=false
```

Production-сборка создаётся в `dist/english-bloom/browser/`. Команда сборки не запускает сервер.

## Компоненты

| Компонент        | Назначение                                               |
| ---------------- | -------------------------------------------------------- |
| `Header`         | Логотип и ссылки на разделы страницы                     |
| `Hero`           | Приветствие, идея проекта и иллюстрация                  |
| `LearningTracks` | Словарный запас, грамматика и полезные фразы с примерами |
| `WordOfDay`      | Слово bloom, перевод и пример употребления               |
| `Footer`         | Информация о проекте и ссылка наверх                     |

Все пять компонентов импортированы в `src/app/app.ts`, перечислены в `imports` и подключены через селекторы в `src/app/app.html`. Корневой `App` объединяет страницу. У каждого компонента отдельные `.ts`, `.html` и `.scss` файлы; общие стили находятся в `src/styles.scss`.

## Настройки проекта

- Angular 22 и TypeScript; проект создан через Angular CLI.
- Стили SCSS, адаптивная вёрстка для компьютеров и телефонов.
- SSR/SSG и конфигурации AI-инструментов отключены.
- Router, Signals, формы, API и сервисы в приложении не используются.
- Навигация работает через обычные ссылки на разделы страницы.
- Шрифты системные; иллюстрация и favicon — локальные SVG. Внешние сервисы и ключи не нужны.
- `node_modules/`, `dist/` и `.angular/` исключены из Git. `package-lock.json` сохранён для воспроизводимой установки.

Команда создания основы:

```bash
npx @angular/cli@22 new english-bloom --style=scss --routing=false --ssr=false --ai-config=none --package-manager=npm
```

Компоненты создавались командой `ng generate component <name> --skip-tests`. Базовые тесты корневого компонента сохранены и адаптированы к заголовку страницы.

Документация: [установка Angular](https://angular.dev/installation), [Angular CLI](https://angular.dev/cli), [компоненты](https://angular.dev/guide/components).
